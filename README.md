# EC Body Essence & Spa — Demo Website

A standalone responsive concept site for EC Body Essence & Spa.

## Run it

Double-click `index.html` and it will open in your browser. No Node.js, npm, or build step is required.

## Files

- `index.html` — page structure and business content
- `styles.css` — responsive premium spa design
- `script.js` — mobile menu, reveal animations, demo booking form
- `assets/` — placeholder folder for real business photography/logo assets

## Before production

1. Replace the abstract visual blocks with the business's real photos.
2. Confirm the exact address wording, service menu, hours, phone/WhatsApp details and pricing with the owner.
3. Connect the booking form to WhatsApp, email, a booking provider, or a backend.
4. Replace the concept logo with the official business logo if available.

The current demo intentionally avoids inventing service prices.
